## Commands

```shell
git config --global user.name "Alfredo Linguini"
git config --global user.email "a.linguini@ratatouille.fr"

git config credential.helper store

git branch some-branch
git switch some-branch

git switch --create some-branch
git switch -c some-branch

git branch --delete some-branch

git push --set-upstream origin some-branch
git push -u origin some-branch

git push origin -d some-branch
git push origin -D some-branch

git status
git add .
git commit --message "initial commit"
git commit -m "initial commit"
git push

vim ~/.gitconfig
vim ~/.git-credentials
```
